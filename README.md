# Binary Tree AAC Speller

A simple AAC-style speller that runs **entirely in the browser** and only uses **Left** and **Right** arrow keys.

## How it works

- Letters are arranged in a binary tree.
- Press **Left** for `0` and **Right** for `1` to navigate from the root.
- When you stop pressing keys for a short delay, the current letter is committed into the typed text area.

## Run (no install required)

1. Download or clone this folder.
2. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).

That’s it — no Node.js, build tools, or dependencies are required.
